# 2026-10-19 活动平台三项改造（仅虚构数据）

1. 首页 / 显示 21:9 SVG 卡通活动卡片、报名与活动时间及材料要求；我的活动和一码通截图恢复移至 /my，工作人员登录移至 /adminlogin，后台操作位于 /admin。
2. 内置 5 种原创 SVG 卡通模板。负责人可替换模板，也可上传严格小于 100 KB、viewBox 为 21:9 的静态 SVG。服务端拒绝脚本、事件处理、外部资源、动画和危险 XML；只把重新序列化的安全图形保存于 Stage R2 独立 event-banners/ 前缀。
3. 新建活动单独设置报名时间，D1 0004_join_window.sql 仅追加两个 nullable 字段；旧活动使用创建时间到活动结束作为报名窗口。
4. 后台审核用表格展示序号、自填资料、材料和签到状态。支持行勾选、Shift 连续多选、全选、通过勾选与驳回原因、确认后批量提交。图片在右侧面板预览，支持顺序切换；后台权限和每条审计均由服务端验证。
5. 智能路由代码在 smart-route/ 下，默认彻底关闭；只对匿名公网页面提供带 IP CIDR + 签名心跳 + 浏览器健康探测的候选 LAN 跳转。一码通、App、工作人员登录不自动跨域。部署需要校区实际公网出口 CIDR、HTTPS LAN 域名、DNS/证书、可靠 API/Cookie 处理，详见 smart-route/README.md。

Stage 迁移顺序：先备份独立虚构数据 D1，再应用 0004；通过单测、Wrangler dry-run、CI 后只部署 activity-stage.10273055.xyz。切勿触碰正式数据、activity.10273055.xyz 的生产路由或 audition 站点。
上线边界：此改造不意味着真实学生资料可上线；仍需独立确认身份与隐私治理、SVG 安全、审计并发和校园网络切换。
