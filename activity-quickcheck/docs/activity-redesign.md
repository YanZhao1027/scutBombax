# 花工木棉活动 2.0：卡片首页、独立后台、批量审核

开发范围：独立的虚构数据 Stage，必须继续启用 SYNTHETIC_ONLY=true。此项目没有开放真实学生资料收集。

## 学生首页

学生访问 / 时，首屏主要内容是两列大卡片（手机一列），每张包含 21:9 SVG 卡通横幅、活动主题、独立报名起止时间、活动开始及结束时间、主办方要求与「免登录报名」入口。五种原创 SVG：音乐、志愿、体育、科创、文化社团。首页不出现工作人员账号密码表单。旧截图恢复与 Android 加密票夹保留在页面尾部的折叠入口，不增加学生用户系统或修改一码通的固定二维码。

右上角「主办方管理」进入 /adminlogin/；已登录主办方进入 /admin/ 管理工作台。后台不重复学生活动卡片，而是在下拉框中选择被授权活动，完成创建、审核、扫码、人员授权和名单导出。服务端仍按工作人员 Session 和逐活动岗位授权控制。

活动录入提供独立报名开放/截止时间（不能晚于活动结束），并提供五种 SVG 卡通主题选项。既有 Stage 活动按历史创建时间和活动结束时间决定报名窗口；迁移不会改变现有报名、核销或一本一码凭证。

## 自定义 SVG 安全要求

主办方可以选择小于 100,000 字节的 SVG 来替换当前活动横幅。必须是 UTF-8、具有 21:9 viewBox、Content-Type image/svg+xml。服务端通过 saxes XML SAX 解析，并严格重建只含几何形状、颜色、局部渐变的安全 SVG。script、foreignObject、style、嵌入文字或图片、事件属性、href、DOCTYPE、外部实体、CSS、动画等一律拒绝。不会原样托管上传源码；清洗后储存在私有 R2，读取时设置 CSP sandbox、禁脚本与内容嗅探响应头。只有活动负责人可以替换，不赋权给审核员、扫码员或学生。

## Excel 式批量审核

表格提供序号、选择、自填姓名、学号、材料张数、更新时间、当前状态、通过勾选、驳回按钮和备注；支持 Shift 连续多选、全选、批量标记通过/驳回。点击某人的证明材料时，右侧出现预览大图，支持上一张/下一张在所有待审申请材料之间切换，窄屏改成浮层。只在明确点击时请求受控图片，不会匿名公开 R2 图片。

审核决定先缓存在浏览器里，明确确认后再提交给后端。后端单次最多 60 条，前端可分批，逐条进行岗位权限、报名状态、材料存在性和更新时间乐观锁校验。部分失败会返回明确失败条目，成功记录不会误报为失败；不同记录不构成跨记录原子事务，网络中断后应先刷新核查，不能直接重新提交。后台自动刷新不会覆盖未提交勾选。原有单条审核、扫码、人工签到和 CSV 导出保持不变。

## 上线边界

先跑完整 Node 回归及 Wrangler dry-run，备份 Stage D1 后仅执行 0004_event_branding.sql；不能执行正式环境迁移。智能路由的 SQL 在 campus/router_schema.sql 中并默认关闭，不创建真实 DNS / Tunnel。实际 Stage 网站部署后再由用户验收手机首页卡片与批量审核。真实学生数据、活动官方授权及个人资料治理仍须单独批准。
